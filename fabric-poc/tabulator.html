What this comparison includes

Native Tabulator: cell-range selection, clipboard, numeric editing, sorting, column filters, resizing, column menus, frozen columns/rows, column totals, CSV and print generation.

Not built into this demo: a font/colour toolbar, selected-range sum/count, multi-user presence or shared editing. Those need application integration; they are not presented as native features.

Sample edits remain in memory. No database changes. The row-number column is frozen. Tabulator warns about combining frozen data columns with range selection; that combination is not enabled in this comparison. The preview uses Tabulator’s native HTML exporter.
